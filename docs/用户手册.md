## 1. 安装

### 1.1 安装 MoonBit 工具链

**Linux / macOS：**
```bash
curl -fsSL https://cli.moonbitlang.com/install/unix.sh | bash
```

**Windows：**
```powershell
irm https://cli.moonbitlang.com/install/windows.ps1 | iex
```

验证安装：
```bash
moon version
```

> **V0.9 要求**：MoonBit 工具链最低版本 `0.1.20260819`

### 1.2 克隆项目

```bash
git clone https://github.com/toadium/moon_hydro.git
cd moon_hydro
```

### 1.3 编译检查

```bash
moon check
```

## 2. 快速开始

### 2.1 运行完整演示

```bash
moon run --target native backend
```

输出包含所有 20 个子命令的执行结果。

### 2.2 运行特定子命令

V0.9 引入了 CLI dispatch 分发器，可通过环境变量指定子命令：

```bash
MOON_HYDRO_CMD=sim moon run --target native backend       # 单次仿真
MOON_HYDRO_CMD=calibrate moon run --target native backend  # SCE-UA 率定
MOON_HYDRO_CMD=ai_forecast moon run --target native backend # AI 混合预报
MOON_HYDRO_CMD=flood moon run --target native backend       # 洪水推演
MOON_HYDRO_CMD=help moon run --target native backend        # 帮助信息
```

> **说明**：当前 MoonBit 标准库暂无 argv 模块，dispatch 分发器已就绪，通过环境变量 `MOON_HYDRO_CMD` 传入子命令名。待 argv 支持后将直接接入命令行参数。

### 2.3 运行测试

```bash
# 全部测试（373 个测试）
moon test --target native

# 指定后端
moon test --target wasm-gc
moon test --target js
moon test --target wasm
```

### 2.4 运行前端演示

```bash
moon run --target native frontend
```

## 4. 仿真流程

### 4.1 新安江模型仿真

新安江模型是三水源四层蒸发产流模型，核心参数 11 个：

| 参数 | 含义 | 默认值 |
|------|------|--------|
| `wm` | 流域平均张力水蓄水容量 (mm) | 120.0 |
| `wum` | 上层张力水蓄水容量 (mm) | 20.0 |
| `wlm` | 下层张力水蓄水容量 (mm) | 60.0 |
| `wdm` | 深层张力水蓄水容量 (mm) | 40.0 |
| `b` | 蓄水容量曲线指数 | 0.3 |
| `im` | 不透水面积比例 | 0.01 |
| `c` | 蒸散发系数 | 1.0 |
| `sm` | 流域平均自由水蓄水容量 (mm) | 20.0 |
| `ex` | 自由水容量曲线指数 | 1.5 |
| `kg` | 地下水消退系数 | 0.35 |
| `ki` | 壤中流消退系数 | 0.35 |

> **V0.9 改进**：新安江模型状态新增 `qs`/`qi`/`qg` 字段，逐步仿真时正确传递前期状态量，退水过程计算更准确。

### 4.2 代码示例

```moonbit
let model = @shared.XinanjiangModel::new(
  params=@shared.XinanjiangParams::default(),
  area=100.0, dt=1.0,
)
let forcings : Array[@shared.ForcingData] = [
  { rainfall: 10.0, evaporation: 2.0, datetime: "t0" },
  { rainfall: 20.0, evaporation: 1.0, datetime: "t1" },
]
let result = model.run(forcings)
// result.runoff_series : Array[Double]
// result.nse / kge / pbias
```

### 4.3 浅水方程仿真

> **V0.9 改进**：SWE 边界处理改为不可变方式，`apply_boundary` 不再就地修改输入网格。

```moonbit
let grid = @shared.SWEGrid1D::uniform(nx=50, dx=1.0, h0=1.0)
let config : @shared.SWESolverConfig = {
  dt: 0.01, n_steps: 50, cfl: 0.4,
  boundary: {
    left: @shared.SWEBoundaryType::SolidWall,
    right: @shared.SWEBoundaryType::Transmissive,
  },
}
let result = grid.run(config)
```

### 4.4 耦合仿真

> **V0.9 改进**：`run_couple` 现在正确返回 `runoff_series`，不再为空。

```moonbit
let result = @shared.couple_run(
  xaj_model, grid, coupling_params, swe_boundary, forcings, 0.005,
)
// result.runoff_series  -- 径流过程（V0.9 修复）
```

## 5. 参数率定

### 5.1 SCE-UA 全局优化

```moonbit
let cfg : @shared.SCEUAConfig = {
  max_iter: 50, n_complexes: 4, complex_size: 0,
  cce_iterations: 0, seed: 42, target_metric: "nse",
  params: @shared.default_calib_params(),
  convergence_threshold: 0.000001, max_no_improve: 20,
}
let result = @shared.sceua_calibrate(cfg, area=100.0, dt=1.0, forcings, observed)
```

### 5.2 DDS 动态维度搜索

> **V0.9 改进**：DDS 现在正确读取 `target_metric` 配置，支持 NSE/KGE 等多种目标函数。

```moonbit
let cfg : @shared.DDSConfig = {
  max_iter: 30, r: 0.2, seed: 123,
  target_metric: "kge",  // V0.9：正确支持 KGE 目标
  params: @shared.default_calib_params(),
  max_no_improve: 100,
}
let result = @shared.dds_calibrate(cfg, area=200.0, dt=1.0, forcings, observed)
```

### 5.3 率定结果查看

V0.9 修复了前端 TEA 架构中率定结果丢弃的问题。`CalibrationCompleted` 消息现在将率定结果存入模型状态：

```moonbit
let model2 = @lib.update(model, @lib.Msg::CalibrationCompleted(calib_result))
// model2.sim_result.nse 现在包含率定最优 NSE 值
```

## 7. 持久化存储

### 7.1 DataStore 内存操作

```moonbit
let store = @persistence.DataStore::new()
store.save_scheme(scheme)
let loaded = store.load_scheme("scheme_001")
let json_str = store.to_json_string()
```

### 7.2 文件持久化（native 后端）

> **V0.9 安全增强**：C FFI 文件读写增加了边界检查和大小验证，防止 >2GB 文件导致缓冲区溢出。新增 `hydro_file_exists` 和 `hydro_delete_file` FFI 函数。

```moonbit

```

### 7.3 数据类型

| 类型 | 说明 |
|------|------|
| `SimulationScheme` | 仿真方案（参数 + 驱动 + 元数据） |
| `ResultRecord` | 仿真结果记录（洪峰 + NSE/KGE + 径流过程） |
| `ParameterSet` | 参数集（参数 + 流域 + 描述） |
| `DataStore` | 数据存储（方案 + 结果 + 参数集） |

## 9. 前端 TEA 架构

### 9.1 Model / Msg / Update / View

沐澜水文前端采用 The Elm Architecture (TEA) 分层设计，V0.9 进一步强化了纯函数式约束：

```moonbit
let model = @lib.AppModel::initial()
let m1 = @lib.update(model, @lib.Msg::NavigateTo(@lib.Page::SimPage))
let m2 = @lib.update(m1, @lib.Msg::RunSimulation)
let view_node = @lib.view(m2)
let report = @lib.view_to_text(view_node)
```

### 9.2 V0.9 纯函数式改进

- **View 纯函数化**：`view_simulation` 和 `view_history` 不再使用 `push` 副作用，改用函数式数组构造
- **AddHistory 函数式**：使用 `model.history + [entry]` 操作符追加，仅截断时用循环
- **26 个 Msg 变体**：覆盖导航、仿真、率定、评价、批量、UI 控制、错误处理、历史记录等

### 9.3 浏览器内试算

```moonbit
let result = @lib.quick_run([10.0, 20.0, 5.0, 0.0, 30.0])
let json_response = @lib.slim_json_endpoint(json_request)
```

## 15. 常见问题

### Q: 如何切换后端？

```bash
moon run --target native backend    # 原生二进制
moon run --target wasm-gc frontend  # 浏览器 Wasm-GC
moon run --target js frontend       # 纯 JavaScript
```

### Q: 如何运行特定子命令？

```bash
# V0.9：通过环境变量指定子命令
MOON_HYDRO_CMD=sim moon run --target native backend
MOON_HYDRO_CMD=calibrate moon run --target native backend
```

### Q: 文件持久化在 wasm/js 后端不可用？

文件 I/O 仅支持 native 后端（C FFI）。wasm/js 后端请使用 `to_json_string()` 获取 JSON 字符串，通过浏览器 localStorage 或 IndexedDB 持久化。

### Q: 如何添加自定义流域？

```moonbit
let custom_case : @shared.BasinCase = {
  name: "自定义流域",
  area: 500.0, dt: 2.0,
  params: @shared.XinanjiangParams::default(),
  forcings: [...],
}
let task = @shared.create_task_from_basin("custom", custom_case)
```

### Q: 测试如何运行？

```bash
moon test                                    # 默认后端
moon test --target native                    # native 后端（373 个测试）
moon test shared --filter "Xinanjiang*"     # 指定过滤
moon coverage analyze                        # 覆盖率分析
```
