## 1. 安装

### 1.1 安装 MoonBit 工具链

**Linux / macOS：**
```bash
curl -fsSL https://cli.moonbitlang.com/install/unix.sh | bash
```

**Windows：**
```powershell
# 下载安装器并运行
irm https://cli.moonbitlang.com/install/windows.ps1 | iex
```

验证安装：
```bash
moon version
```

### 1.2 克隆项目

```bash
git clone https://github.com/toadium/moon_hydro.git
cd moon_hydro
```

### 1.3 编译检查

```bash
moon check
```

## 4. 仿真流程

### 4.1 新安江模型仿真

新安江模型是三水源四层蒸发产流模型，核心参数 11 个：

| 参数 | 含义 | 默认值 |
|------|------|--------|
| `wm` | 流域平均张力水蓄水容量 (mm) | 120.0 |
| `wum` | 上层张力水蓄水容量 (mm) | 20.0 |
| `wlm` | 下层张力水蓄水容量 (mm) | 60.0 |
| `wdm` | 深层张力水蓄水容量 (mm) | 40.0 |
| `b` | 蓄水容量曲线指数 | 0.3 |
| `im` | 不透水面积比例 | 0.01 |
| `c` | 蒸散发系数 | 1.0 |
| `sm` | 流域平均自由水蓄水容量 (mm) | 20.0 |
| `ex` | 自由水容量曲线指数 | 1.5 |
| `kg` | 地下水消退系数 | 0.35 |
| `ki` | 壤中流消退系数 | 0.35 |

### 4.2 代码示例

```moonbit
// 创建新安江模型
let model = @shared.XinanjiangModel::new(
  params=@shared.XinanjiangParams::default(),
  area=100.0,    // 流域面积 km²
  dt=1.0,        // 计算时段 h
)

// 构造气象驱动
let forcings : Array[@shared.ForcingData] = [
  { rainfall: 10.0, evaporation: 2.0, datetime: "t0" },
  { rainfall: 20.0, evaporation: 1.0, datetime: "t1" },
  { rainfall: 5.0,  evaporation: 3.0, datetime: "t2" },
]

// 运行仿真
let result = model.run(forcings)
// result.runoff_series : Array[Double]  — 径流过程
// result.nse / kge / pbias              — 评价指标
```

### 4.3 浅水方程仿真

```moonbit
// 1D 浅水方程
let grid = @shared.SWEGrid1D::uniform(nx=50, dx=1.0, h0=1.0)
let config : @shared.SWESolverConfig = {
  dt: 0.01, n_steps: 50, cfl: 0.4,
  boundary: {
    left: @shared.SWEBoundaryType::SolidWall,
    right: @shared.SWEBoundaryType::Transmissive,
  },
}
let result = grid.run(config)

// 2D 浅水方程（dam-break）
let grid2d = @shared.SWEGrid2D::uniform(nx=20, ny=20, dx=1.0, dy=1.0, h0=0.1)
ignore(grid2d.set_block(i0=0, i1=10, j0=0, j1=20, h_value=2.0))
let result2d = grid2d.run(config2d)
```

### 4.4 耦合仿真

```moonbit
let result = @shared.couple_run(
  xaj_model, grid, coupling_params, swe_boundary, forcings, 0.005,
)
// result.stable               — 耦合稳定性
// result.lateral_inflow_series — 侧向入流过程
// result.water_level_series   — 河道水位过程
```

## 5. 参数率定

### 5.1 SCE-UA 全局优化

SCE-UA（Shuffled Complex Evolution）是全局优化算法，适合高维参数空间：

```moonbit
let cfg : @shared.SCEUAConfig = {
  max_iter: 50,           // 最大迭代
  n_complexes: 4,         // 复形数
  complex_size: 0,        // 复形大小（0=自动）
  cce_iterations: 0,      // CCE 迭代（0=自动）
  seed: 42,               // 随机种子
  target_metric: "nse",   // 目标 metric
  params: @shared.default_calib_params(), // 11 个参数范围
  convergence_threshold: 0.000001,
  max_no_improve: 20,
}
let result = @shared.sceua_calibrate(
  cfg, area=100.0, dt=1.0, forcings, observed,
)
// result.best_metric  — 最优 NSE
// result.best_params  — 最优参数
// result.converged    — 是否收敛
```

### 5.2 DDS 动态维度搜索

DDS 适合高维参数空间，收敛速度快：

```moonbit
let cfg : @shared.DDSConfig = {
  max_iter: 30, r: 0.2, seed: 123,
  target_metric: "nse",
  params: @shared.default_calib_params(),
}
let result = @shared.dds_calibrate(
  cfg, area=200.0, dt=1.0, forcings, observed,
)
```

### 5.3 性能对比

| 算法 | 平均耗时 | 吞吐量 | 特点 |
|------|----------|--------|------|
| SCE-UA | 35.4 ms | 28.2 ops/s | 全局收敛性好 |
| DDS | 1.6 ms | 625 ops/s | 高维快速 |

## 6. 持久化存储

### 6.1 DataStore 内存操作

```moonbit
let store = @persistence.DataStore::new()

// 保存仿真方案
let scheme : @persistence.SimulationScheme = {
  id: "scheme_001",
  name: "闽江竹岐基准方案",
  basin_name: "闽江竹岐",
  area: 54500.0, dt: 6.0,
  params: @shared.XinanjiangParams::default(),
  forcings: [...],
  created_at: timestamp, updated_at: timestamp,
}
store.save_scheme(scheme)

// 查询
let loaded = store.load_scheme("scheme_001")
let ids = store.list_schemes()
store.delete_scheme("scheme_001")
```

### 6.2 JSON 序列化

```moonbit
// 序列化为 JSON 字符串
let json_str = store.to_json_string()

// 从 JSON 反序列化
let store2 = @persistence.DataStore::from_json_string(json_str)
```

### 6.3 文件持久化（native 后端）

```moonbit
// 保存到文件
store.save_to_file("data/store.json")

// 从文件加载
let loaded = @persistence.DataStore::load_from_file("data/store.json")
```

### 6.4 数据类型

| 类型 | 说明 |
|------|------|
| `SimulationScheme` | 仿真方案（参数 + 驱动 + 元数据） |
| `ResultRecord` | 仿真结果记录（洪峰 + NSE/KGE + 径流过程） |
| `ParameterSet` | 参数集（参数 + 流域 + 描述） |
| `DataStore` | 数据存储（方案 + 结果 + 参数集） |

## 7. 任务调度

### 7.1 基本用法

```moonbit
let scheduler = @shared.TaskScheduler::new()

// 添加任务
let task : @shared.SimTask = {
  task_id: "task_001",
  basin_name: "闽江竹岐",
  params: @shared.XinanjiangParams::default(),
  forcings: [...],
  area: 54500.0, dt: 6.0,
  observed: [],
}
scheduler.add_task(task)

// 执行所有任务，带进度回调
scheduler.run(progress => {
  println("进度: \{progress.percentage}% (\{progress.completed}/\{progress.total})")
})

// 获取结果
let results = scheduler.get_results()
let report = scheduler.progress_report()
```

### 7.2 批量执行

```moonbit
let tasks = @shared.create_basin_tasks([
  @shared.synthetic_benchmark_case(),
  @shared.zhuyi_basin_case(),
  @shared.feiyunjiang_basin_case(),
])

let results = @shared.run_tasks(tasks, progress => {
  println("已完成: \{progress.completed}/\{progress.total}")
})
```

## 10. 常见问题

### Q: 如何切换后端？

```bash
moon run --target native backend    # 原生二进制
moon run --target wasm-gc frontend  # 浏览器 Wasm-GC
moon run --target js frontend       # 纯 JavaScript
```

### Q: 文件持久化在 wasm/js 后端不可用？

文件 I/O 仅支持 native 后端（C FFI）。wasm/js 后端请使用 `to_json_string()` 获取 JSON 字符串，通过浏览器 localStorage 或 IndexedDB 持久化。

### Q: 如何添加自定义流域？

```moonbit
let custom_case : @shared.BasinCase = {
  name: "自定义流域",
  area: 500.0, dt: 2.0,
  params: @shared.XinanjiangParams::default(),
  forcings: [...],
}
let task = @shared.create_task_from_basin("custom", custom_case)
```

### Q: 测试如何运行？

```bash
moon test                                    # 默认后端
moon test --target native                    # native 后端
moon test shared --filter "Xinanjiang*"     # 指定过滤
moon coverage analyze                        # 覆盖率分析
```
