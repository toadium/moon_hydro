## 1. 环境要求

### 1.1 MoonBit 工具链

| 项目 | 最低版本 | 推荐版本 |
|------|----------|----------|
| MoonBit | 0.1.20260827 | 最新稳定版 |

安装方式：
```bash
# Linux / macOS
curl -fsSL https://cli.moonbitlang.com/install/unix.sh | bash

# Windows
irm https://cli.moonbitlang.com/install/windows.ps1 | iex
```

### 1.2 系统要求

| 平台 | 架构 | 后端支持 | 备注 |
|------|------|----------|------|
| Linux | x86_64 / arm64 | wasm, wasm-gc, js, native | 推荐 |
| macOS | x86_64 / arm64 | wasm, wasm-gc, js, native | 推荐 |
| Windows | x86_64 | wasm, wasm-gc, js, native | native 需 MSVC |

### 1.3 依赖说明

本项目仅依赖 `moonbitlang/core/*`（标准库），无第三方依赖。

| 依赖包 | 用途 |
|--------|------|
| `moonbitlang/core/math` | 数学函数 |
| `moonbitlang/core/json` | JSON 序列化 |
| `moonbitlang/core/encoding/utf8` | UTF-8 编解码（persistence C FFI） |
| `moonbitlang/core/env` | 环境变量、时间戳、随机数 |
| `moonbitlang/core/quickcheck/splitmix` | 随机数生成 |

### 1.4 native 后端额外依赖

native 后端使用 C FFI 实现文件 I/O，需要系统 C 编译器：

| 平台 | 编译器 | 说明 |
|------|--------|------|
| Linux | gcc / clang | 默认已安装 |
| macOS | clang (Xcode) | `xcode-select --install` |
| Windows | MSVC | 需安装 Visual Studio Build Tools |

> **V0.9.3 安全增强**：C FFI 文件读写已增加边界检查和大小验证，防止 >2GB 文件导致缓冲区溢出。新增 `hydro_file_exists` 和 `hydro_delete_file` 安全 FFI 函数。

## 2. 构建指南

### 2.1 编译检查

```bash
moon check
```

> V0.9.3 状态：0 错误，0 警告

### 2.2 构建（指定后端）

```bash
# native 后端（原生二进制）
moon build --target native

# wasm-gc 后端（现代浏览器）
moon build --target wasm-gc

# wasm 后端（Wasm 兼容环境）
moon build --target wasm

# js 后端（纯 JavaScript）
moon build --target js
```

### 2.3 运行

```bash
# 运行后端 CLI（默认 demo 子命令）
moon run --target native backend

# 运行特定子命令（V0.9.3 新增）
MOON_HYDRO_CMD=sim moon run --target native backend

# 运行前端
moon run --target native frontend
```

### 2.4 测试

```bash
# 全部测试（373 个测试）
moon test

# 指定后端
moon test --target wasm-gc

# 指定包
moon test shared

# 过滤测试
moon test shared --filter "Xinanjiang*"

# 覆盖率分析
moon coverage analyze
```

### 2.5 格式化与接口生成

```bash
moon fmt      # 格式化代码
moon info     # 生成 pkg.generated.mbti 接口文件
```

## 3. 四后端部署

### 3.1 native 后端（服务器部署）

**适用场景：** Linux/Windows/macOS 服务器、CLI 工具、高性能计算

```bash
# 构建
moon build --target native

# 产物位置：_build/native/release/build/backend/backend.exe
# 运行
moon run --target native backend
```

**Release 构建：**
```bash
moon build --target native --release
```

**特点：**
- 最高性能
- 支持 C FFI（文件 I/O 等系统调用）
- 持久化模块文件读写可用
- V0.9.3：C FFI 安全增强（边界检查 + 大小验证）

### 3.2 wasm-gc 后端（现代浏览器）

**适用场景：** 现代浏览器、WebView、Wasm 云函数

```bash
moon build --target wasm-gc
# 产物：_build/wasm-gc/release/build/frontend/frontend.wasm
```

**特点：**
- GC 支持，内存效率高
- 浏览器内直接试算
- 文件 I/O 不可用（使用 localStorage 替代）

### 3.3 wasm 后端（Wasm 兼容环境）

**适用场景：** Wasm 兼容环境、老旧浏览器

```bash
moon build --target wasm
```

### 3.4 js 后端（纯 JavaScript）

**适用场景：** Node.js、老旧浏览器、JS 生态集成

```bash
moon build --target js
```

### 3.5 后端对比

| 后端 | 性能 | 文件 I/O | GC | 适用场景 |
|------|------|----------|-----|----------|
| native | 最高 | ✅ | 系统GC | 服务器、CLI |
| wasm-gc | 高 | ❌ | WasmGC | 现代浏览器 |
| wasm | 中 | ❌ | 引用计数 | Wasm 环境 |
| js | 低 | ❌ | JS GC | Node.js |

## 4. CI/CD 配置

### 4.1 工作流概览

| 工作流 | 文件 | 触发条件 | 内容 |
|--------|------|----------|------|
| CI | `.github/workflows/ci.yml` | push/PR → main | 编译检查 + 四后端测试 + 格式检查 |
| PR Check | `.github/workflows/pr-check.yml` | PR → main | 编译检查 + wasm-gc 快速测试 |
| Release | `.github/workflows/release.yml` | tag `v*` | 四后端构建 + 测试门禁 + GitHub Release |

### 4.2 CI 工作流

```yaml
# .github/workflows/ci.yml 核心步骤
- 安装 MoonBit 工具链 (0.1.20260827+)
- moon check              # 编译检查
- moon test --target wasm-gc
- moon test --target wasm
- moon test --target js
- moon test --target native
- moon fmt --check        # 格式检查
```

### 4.3 Release 工作流

> **V0.9.3 新增**：Release 工作流已添加测试门禁，所有测试通过后才创建 Release。

```bash
# 创建 tag 触发发布
git tag v0.9.3
git push origin v0.9.3
```

Release 工作流流程：
1. 运行全部测试（373 个测试）—— **测试门禁**
2. 四后端构建（native / wasm-gc / wasm / js）
3. 创建 GitHub Release，附带构建产物

### 4.4 自定义 CI

如需添加自定义 CI 步骤，编辑 `.github/workflows/ci.yml`：

```yaml
- name: 自定义步骤
  run: |
    moon test --target native
    moon coverage analyze
```

## 6. 性能优化

### 6.1 性能基准

| 基准项 | 平均耗时 | 吞吐量 | 说明 |
|--------|----------|--------|------|
| 新安江仿真 | 0.04 ms | 25,000 ops/s | 5 步仿真 |
| 1D SWE | 4.37 ms | 229 ops/s | 50 单元 × 50 步 |
| 2D SWE | 209 ms | 4.8 ops/s | 20×20 网格 × 30 步 |
| SCE-UA 率定 | 35.4 ms | 28.2 ops/s | 50 次迭代 |
| DDS 率定 | 1.6 ms | 625 ops/s | 30 次迭代 |
| 批量仿真 | 0.5 ms | 2,000 ops/s | 5 流域 |
| 耦合仿真 | 1.5 ms | 667 ops/s | 5 步耦合 |

### 6.2 优化建议

1. **使用 native 后端**：生产环境使用 `--target native --release`
2. **批量仿真**：使用 `TaskScheduler` 批量执行，减少重复初始化
3. **JSON 序列化**：大量数据序列化使用 `to_json().stringify()` 而非逐字段拼接
4. **内存管理**：MoonBit 有 GC，无需手动管理，但避免在热循环中创建大量临时对象

### 6.3 运行基准测试

```bash
MOON_HYDRO_CMD=bench moon run --target native backend
```
