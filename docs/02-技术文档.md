## 一、概述

沐澜水文是一套基于MoonBit全栈多后端架构的分布式新安江模型+浅水方程水动力耦合流域洪水智能预报系统。技术定位为：以MoonBit单语言完成仿真内核、后端服务、前端界面全栈开发，前后端共享唯一一套数据模型，一套源码经四后端编译覆盖服务器集群、浏览器、Wasm云函数、嵌入式边缘终端全部署场景。仿真内核参考Rust crates.io发布的hydro-suite套件（hydro-core / hydro-xinajiang / hydro-calib）接口规范与算法逻辑实现，以Python开源实现OuyangWenyu/hydromodel作为数值比对基准，与原版Rust代码相对误差＜0.1%，同等网格条件下仿真效率为Python版本15~40倍。

## 三、系统架构

### 3.1 MoonBit Workspace 工程目录结构

```
moon_xaj_hydro/
├── moon.work                   # Workspace总配置、多后端编译目标配置、依赖锁定
├── shared/                     # 全局共享层：前后端+所有后端共用唯一一套数据模型与内核
│   ├── model.mbt               # 核心结构体：XinanjiangParams、XinanjiangState、ForcingData、SimResult、CalibConfig
│   ├── hydro_trait.mbt         # HydroModel统一通用模型特征接口
│   ├── xaj_core.mbt            # 完整移植后的新安江演算内核
│   ├── swe_core.mbt            # 二维浅水方程求解内核
│   ├── utils.mbt               # 水文通用工具、单位线卷积、评价指标计算函数
│   └── serde_bind.mbt          # 全局统一JSON序列化/反序列化绑定
├── backend/                    # Proton后端，默认编译native目标，同时支持wasm-wasi-gcc、JS目标
│   ├── main.mbt                # Proton服务入口、路由配置、中间件、跨域处理
│   ├── api_routes.mbt          # 全部RESTful接口定义与业务逻辑
│   ├── db_sqlite.mbt           # 数据库交互、数据读写、方案存储

└── frontend/                   # Rabbita前端，默认编译wasm-gc目标，兼容JS编译目标
    ├── main.mbt                # Rabbita前端应用入口
    ├── model_bind.mbt          # 前端全局状态与shared共享模型绑定
    ├── msg_enum.mbt            # 全部前端交互消息枚举定义
    ├── update_logic.mbt        # TEA架构状态更新逻辑
    ├── view_layout.mbt         # 整体页面布局、组件排布
    ├── chart_render.mbt        # 时序曲线图、热力图渲染逻辑
    └── wasm_slim_model.mbt     # 前端轻量化仿真内核封装
```

### 3.2 模块职责说明

| 层 | 目录 | 职责 |
|----|------|------|
| shared共享层 | `shared/` | 定义唯一一套水文数据结构与算法内核，四后端完全复用，无需条件编译 |
| backend后端层 | `backend/` | 基于Proton搭建RESTful API、数据库持久化、异步任务调度，默认native目标 |
| frontend前端层 | `frontend/` | 基于Rabbita+Rui搭建TEA架构可视化平台，默认wasm-gc目标 |

### 3.3 整体模型耦合分层架构

```
驱动层（气象时序、流域空间属性、边界约束）
        ↓
概念性水文层（三水源新安江：分层蒸发、蓄满产流、自由水水源划分、坡面汇流）
        ↓
耦合接口层（单元产流量→河道侧向通量；河道水位→地下水储量反馈）
        ↓
水动力演进层（二维SWE有限体积法求解，输出全域水位流速场）
        ↓
评价与率定层（DDS/SCE-UA全局智能寻优 + NSE/KGE/PBIAS精度评价）
        ↓
应用服务层（Proton后端API + Rabbita可视化平台 + 四后端多场景部署）
```

## 四、核心模块设计

### 4.1 shared共享层

#### 4.1.1 xaj_core（新安江演算内核）

- **职责**：参考hydro-suite套件接口规范，完成新安江模型MoonBit原生实现，完成三水源产汇流演算
- **关键接口**：

```moonbit
trait HydroModel {
  fn step(self : Self, forcing : ForcingData, state : Self::State) -> Self::State
  fn run(self : Self, forcings : Array[ForcingData]) -> SimResult
}
```

- **依赖**：moonNum（数组运算）、utils（单位线卷积）

#### 4.1.2 swe_core（浅水方程求解内核）

- **职责**：基于moonNum完成二维有限体积法SWE离散求解，支持地形底坡、河道糙率、上下游边界、侧向入流
- **关键数据结构**：SWEGrid（网格地形、糙率、水深、流速）、SWEBoundary（边界条件类型与值）
- **依赖**：moonNum（矩阵运算、SIMD加速）

#### 4.1.3 coupling（模型双向耦合）

- **职责**：新安江各单元产流量作为河道侧向通量边界；河道水位动态反馈调整流域地下径流储量
- **关键接口**：`fn couple_step(xaj_state, swe_state, coupling_params) -> (XinanjiangState, SWEState)`
- **依赖**：xaj_core、swe_core

#### 4.1.4 hydro_trait（通用模型特征接口）

- **职责**：统一全部水文模型（含未来AI模型）的步进仿真调用规范，支持扩展LSTM、PINN等模块

### 4.2 backend后端层

#### 4.2.1 api_routes（RESTful接口）

- **职责**：封装全套标准化API接口（详见第六章接口设计）
- **依赖**：shared、Proton、serde

#### 4.2.2 db_sqlite（数据库交互）

- **职责**：对接SQLite数据库，实现流域基础信息、气象时序数据、仿真方案、历史结果持久化存储
- **依赖**：sqlite3、shared、serde

#### 4.2.3 task_scheduler（异步任务调度）

- **职责**：异步仿真任务队列、多流域并行调度、仿真进度实时推送、运行日志、异常捕获与错误处理
- **依赖**：async、shared

### 4.3 frontend前端层

#### 4.3.1 TEA架构核心（model_bind / msg_enum / update_logic / view_layout）

- **职责**：严格遵循Rabbita标准TEA架构——全局Model状态、Msg交互消息枚举、Update状态更新逻辑、View界面渲染分层开发
- **依赖**：Rabbita、shared、Rui

#### 4.3.2 wasm_slim_model（浏览器内轻量化试算）

- **职责**：将轻量化新安江内核编译为wasm-gc嵌入前端，实现浏览器内无需后端即可完成小型流域快速试算
- **依赖**：shared（仅xaj_core子集）

## 五、数据模型

### 5.1 核心实体表

| 实体名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| XinanjiangParams | wm、b、im、ke、x、y、kg、ki、cg、ci、cs、n、l、wum、wlm、wdm、c、sm、ex、kg1、ki1、kg2、ki2、fr、t0、t1、td、u0、u1、u2 | Float | 新安江模型17+项参数组合；三层蓄水容量满足 wm = wum + wlm + wdm（wum上层、wlm下层、wdm深层） |
| XinanjiangState | tension_water、free_water、surface_flow、interflow、ground_flow、runoff | Float / Array[Float] | 瞬时仿真状态（可变） |
| ForcingData | rainfall、evaporation、datetime | Float / Array[Float] / DateTime | 气象驱动时序数据 |
| SimResult | runoff_series、state_series、nse、kge、pbias | Array[Float] / Float | 仿真输出结果与评价指标 |
| CalibConfig | algorithm、params_range、max_iter、target_metric | String / Array[(Float,Float)] / Int / String | 率定配置（SCE-UA/DDS） |
| SWEGrid | elevation、roughness、water_depth、velocity_x、velocity_y | Array2D[Float] | 二维浅水方程网格状态 |
| SWEBoundary | boundary_type、boundary_values | Enum / Array[Float] | 边界条件配置 |

### 5.2 数据模型核心优势

1. 所有结构体仅在shared目录内定义唯一一份，前后端类型严格一致；
2. Proton后端返回JSON自动序列化，Rabbita前端接收自动反序列化，杜绝字段缺失、单位不统一、枚举错位；
3. 任意字段修改仅改shared内一处源码，全部后端与前端自动同步，无需人工维护接口文档；
4. 前端可直接调用shared内轻量化仿真函数，浏览器本地试算与后端高精度仿真使用完全同一套算法，结果100%一致。

## 六、接口设计

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/model/run` | 执行单流域完整仿真，返回径流全过程序列 |
| POST | `/api/calibrate/dds` | 启动DDS全局参数自动率定，输出最优17项新安江参数组合 |
| POST | `/api/calibrate/sceua` | 启动SCE-UA全局参数自动率定，输出最优17项新安江参数组合 |
| POST | `/api/evaluate` | 批量计算NSE、KGE、PBIAS指标并自动判定国标GB/T 22482预报等级 |
| POST | `/api/batch` | 多流域、多情景集合批量模拟任务 |

所有接口输入输出均通过serde序列化为JSON，结构体定义位于shared/model.mbt，前后端共用。

## 七、部署与运行

### 7.1 四后端编译目标配置（moon.work）

```toml
[workspace]
members = ["shared", "backend", "frontend"]

[package.shared]
supported_targets = ["native", "wasm-gc", "wasm-wasi-gcc", "js"]

[package.backend]
supported_targets = ["native", "wasm-wasi-gcc", "js"]
default_target = "native"

[package.frontend]
supported_targets = ["wasm-gc", "js"]
default_target = "wasm-gc"
```

### 7.2 四大后端分工与部署场景

| 后端 | 编译产物 | 部署场景 | 用途 |
|------|----------|----------|------|
| wasm-gc | Wasm-GC+JS网页包 | 现代浏览器、WebView | Rabbita前端界面、浏览器内轻量化新安江在线试算、公众预报查询 |
| wasm-wasi-gcc | WASI标准Wasm模块 | Docker容器、云函数、Serverless、Wasm安全沙盒 | 仿真引擎微服务部署、多租户隔离式仿真服务、轻量化云端调度 |
| native | 系统原生高性能二进制 | Linux/Windows/macOS服务器、ARM/RISC-V嵌入式终端 | Proton主后端服务、大规模分布式并行模拟、DDS/SCE-UA批量率定、边缘山洪预警终端 |
| JS | 纯JavaScript代码包 | 老旧浏览器、极简NodeJS环境 | 极端环境下兜底运行、简易演示、轻量脚本调用 |

### 7.3 启动步骤

```bash
# 1. 安装MoonBit工具链
#    参考 https://moonbitlang.com 官方安装指南

# 2. 克隆仓库
git clone https://github.com/toadium/moon_hydro.git
cd moon_hydro

# 3. 安装依赖
moon install

# 4. native后端启动（默认目标）
moon run backend --target native

# 5. wasm-gc前端构建
moon build frontend --target wasm-gc

# 6. 四后端一键打包
moon build --target native && moon build --target wasm-gc && moon build --target wasm-wasi-gcc && moon build --target js
```

## 八、安全与性能

### 8.1 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 仿真效率 | Python版本15~40倍 | 同等分布式流域网格条件下，性能趋近原生Rust |
| 数值精度 | 相对误差＜0.1% | 与Rust原版hydro-suite套件及Python基准OuyangWenyu/hydromodel对比 |
| 并行安全 | 线程安全、无数据竞争 | 多流域并行模拟全程，流域固定参数不可变、仅瞬时状态可变 |
| 跨后端一致性 | 四后端计算结果完全一致 | 使用moonNum统一浮点运算接口，单元测试覆盖全部四类目标 |

### 8.2 安全措施

1. 输入校验：API接口对气象时序、参数范围、边界条件做严格校验，异常输入返回明确错误码；
2. 异常捕获：仿真过程异常捕获与日志记录，避免单任务失败影响全局调度；
3. 边界容错：长时间仿真稳定性测试，边界条件异常输入鲁棒性测试；
4. 沙盒隔离：wasm-wasi-gcc后端运行于WASI安全沙盒，多租户仿真服务隔离。
